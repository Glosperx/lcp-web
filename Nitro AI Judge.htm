Ce trebuie să facem? ヽ( ▀̿ Ĺ̯ ▀̿)ノ♪♬

Principala întrebare de cercetare pe care o punem aici este: putem oare să prezicem complexitatea cuvintelor folosind doar informații oculare? Dacă da, în ce măsură? Cu ce caracteristici? Care metrici de eye-tracking contează cel mai mult ? Cu ce modele putem prezice cel mai bine? Sunt oare participanți pe care dacă îi scoatem, putem prezice mai bine?
Problema principală este că nu avem date de complexitate, doar date de eye tracking ⎚-⎚.

Caracteristicile pentru un cuvânt sunt sub forma unui vector:
x={x1,⋯ ,xn}\mathbf{x} = \{ x_1, \cdots, x_n\}x={x1​,⋯,xn​} unde fiecare componentă x_i e o valoare numerică derivată într-o formă sau alta din metricile de eye tracking.

Pentru fiecare astfel de vector vrem să prezicem o valoare numerică y care reprezintă scorul de complexitate.
Scorul de complexitate depinde de mulți factori, nu doar de proprietățile individuale ale cuvântului, ci și de contextul în care este folosit, funcția și sensurile pe care le are în contextul respectiv.

Resurse permise (▽•̀(oo)•́ ▽)

Aveți voie cu următoarele resurse externe, cu condiția să primiți aprobare de la Sergiu (aprobările se dau individual pe echipă pe mail):

  • liste de cuvinte adiționale, de ex. pentru Engleză există MRC Psycholinguistic Database sau lista Dale-Chall; puteți lua în calcul crearea unor astfel de resurse pentru română
  • seturi de date cu texte adiționale din care să extrageți frecvențe, de exemplu AOCHILDES conține ”child-directed speech transcripts, ordered by the age of the target child” pentru engleză iar Task-ul BabyLM are ca scop antrenarea de LLM cu texte care pot fi plauzibile în dezvoltarea copiilor
  • biblioteci sau API care să comunice cu WordNet sau ConceptNet, pe română există RoWordNet
  • rețele pre-antrenate de tip BERT, RoBERTa, XLM-RoBERTa (obligatoriu trebuie să ruleze local) din care să scoateți vectori de activări sau valori interne, word embeddings
  • LLM maxim 8B: llama, mistral, gemma etc. obligatoriu trebuie să le rulați voi
  • log-probability sau surprisal pentru cuvintele aferente extrase din modele LLM
  • puteți folosi LLMs cu condiția ca acestea să fie open-weights și mai mici de 8B parametri
  • Nu aveți voie cu: API-uri externe și modele closed source (de ex. ChatGPT, Gemini)

Sugestii (∗´ര ᎑ ര`∗)

  • prima și prima dată încercați să aliniați cuvintele de complexity cu cele din eye-tracking
  • cel mai important lucru este să găsiți care metrici de eye-tracking pot fi un proxy bun pentru complexitate
  • apoi să faceți trecerea de la unitățile de măsură originale la o scară de la 0 la 1 potrivită pentru setul de date de complexitate
  • încercați întâi și întâi să folosiți caracteristicile de eye-tracking pentru că acelea sunt singurele date etichetate la care aveți acces
  • încercați metode de regresie și regularizare (Ridge, Lasso)
  • faceți cross-validări pe modele locale și nu vă bazați doar pe leaderboardul public
  • încercați să faceți un testset cu exemplele care au predicții slabe, un fel de testset dificil

Pe lângă metricile de eye tracking, este binecunoscut faptul că complexitatea este corelată cu:

  • caracteristici la nivel de cuvânt: frecvență într-un corpus de dimensiuni mari, frecvență într-un corpus de texte pentru copii, lungime, nr de silabe
  • caracteristici sintactice: parte de vorbire, funcția în propozție
  • caracteristici psiholingvistice: vârsta de achiziție, imaginabilitatea cuvântului
  • caracteristici semantice: număr de sinonime, antonime, cuvinte similare din alte propoziții
  • caracteristici binare: prezența în anumite liste externe, dacă e de tip titlu, dacă este entitate numită etc

Evaluarea (⌐■_■)

Evaluarea se face folosind o metrică customizată folosind două concepte din statistică:

  • Coeficientul de determinare
  • Coeficientul de corelație Pearson

Pentru un set de predicții: p={p1,⋯ ,pm}p = \{p_1, \cdots, p_m\}p={p1​,⋯,pm​}
și un set de valori reale care trebuiau prezise: y={y1,⋯ ,ym}y = \{y_1, \cdots, y_m\}y={y1​,⋯,ym​}
avem coeficientul de determinare dat de suma pătratelor erorilor normalizată după un predictor constant:

Rpy2=1−∑im(yi−pi)2∑im(yi−yˉ)2R_{py}^{2}=1-\frac{ \sum_{i}^{m}(y_i-p_i)^{2} }{ \sum_{i}^{m}(y_{i}-{\bar{y}})^{2} }Rpy2​=1−∑im​(yi​−yˉ​)2∑im​(yi​−pi​)2​
unde este media valorilor reale este yˉ=1m∑imy\bar{y} = \frac{1}{m}\sum_{i}^{m}y yˉ​=m1​∑im​y

Și coeficientul de corelație Pearson:
ρpy=∑i=1m(pi−pˉ)(yi−yˉ)∑i=1m(pi−pˉ)2∑i=1m(yi−yˉ)2\rho_{py}=\frac{\sum_{i=1}^{m}(p_{i}-{\bar{p}})(y_{i}-{\bar{y}})}{\sqrt{\sum_{i=1}^{m}(p_{i}-{\bar{p}})^{2}}\sqrt{\sum_{i=1}^{m}(y_{i}-{\bar{y}})^{2}}}ρpy​=∑i=1m​(pi​−pˉ​)2​∑i=1m​(yi​−yˉ​)2​∑i=1m​(pi​−pˉ​)(yi​−yˉ​)​
forumulat de asemenea și ca cosinusul unghiului dintre valorile standardizate (z-score) după medie și deviația standard ale predicțiilor (sau valorilor reale):
∑i=1m(pi−pˉ)∑i=1m(pi−pˉ)2=p−μpσp\frac{\sum_{i=1}^{m}(p_{i}-{\bar{p}})}{\sqrt{\sum_{i=1}^{m}(p_{i}-{\bar{p}})^{2}}} = \frac{p-\mu_p}{\sigma_p}∑i=1m​(pi​−pˉ​)2​∑i=1m​(pi​−pˉ​)​=σp​p−μp​​

Coeficientul de corelație poate varia între -1, 1 și are următoarele interpretări:

  • 0 când valorile nu sunt corelate
  • 1 sau -1 cand valorile sunt pozitiv sau negativ corelate
  • nedefinit atunci când avem varianță 0 (vector cu valori constante).

Coeficientul de determinare poate varia între -infinit și 1 și are următoarele interpretări:

  • coeficient 0 implică predicții cu valori constante egale cu media valorilor reale (o linie dreaptă care prezice de fiecare dată același număr - media)
  • negativ atunci când predicțiile sunt mai proaste decât o predicție constantă cu media
  • pozitiv atunci când scara predicțiilor (mean squared error) este minimizată și valorile sunt apropiate de cele reale

Metrica noastră de evaluare este dată de media dintre valoarea absolută a coeficientului de corelație și valoarea pozitivă a coeficientului de determinare:
100∗12(∣ρpy∣+max⁡(0,Rpy2))100* \frac{1}{2}( |\rho_{py}| + \max(0, R_{py}^{2}) ) 100∗21​(∣ρpy​∣+max(0,Rpy2​))

from sklearn.metrics import r2_score
from scipy.stats import pearsonr

def eval_metric(y_true, preds):
    y_true = y_true.astype(float)
    preds = preds.astype(float)
    r2 = r2_score(y_true, preds, sample_weight=None, force_finite=True)
    r2 = max(0, r2)
    pears = pearsonr(y_true, preds)[0]
    if np.isnan(pears):
        pears = 0.0
    pears = np.abs(pears)
    return 100*(pears + r2)/2

O soluție performantă ar trebui:

  • să producă predicții cât mai apropiate de valorile reale ale timpilor de citire;
  • să mențină o corelație ridicată între valorile prezise și cele reale;
  • să țină cont de faptul că o corelație bună poate fi obținută chiar și atunci când predicțiile sunt în afara intervalului valorilor reale sau sunt proporționale invers cu acestea (de exemplu, utilizând măsuri bazate pe frecvența cuvintelor);
  • să evite predicțiile constante, deoarece acestea conduc la un scor R² = 0, iar coeficientul Pearson devine nedefinit (NaN).
