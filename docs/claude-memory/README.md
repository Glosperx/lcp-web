# Memorii de sesiune Claude

Snapshot al notitelor de lucru acumulate de Claude Code pe parcursul proiectului,
copiat din `~/.claude/projects/.../memory/` pe 15 septembrie 2026.

`MEMORY.md` e indexul: o linie per memorie, cu link catre fisierul respectiv.
Restul fisierelor sunt cate un fapt fiecare, in general rezultatul masurat al unei
piste de lucru (inchisa sau deschisa), cu cifrele si mecanismul din spate.

Sunt notite interne, nu documentatie. Cifrele dintr-un fisier reflecta ce era
adevarat cand a fost scris, nu neaparat starea curenta a codului.
